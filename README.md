# SQL Analytics Practice

This repository documents my SQL practice as I refresh and strengthen
my data analytics skills.

The exercises progress from SQL fundamentals into practical analytics
problems involving customer behaviour, product analytics, revenue,
funnels, cohorts, retention, and business metrics.

## Topics

- SQL fundamentals
- Filtering and sorting
- Aggregations
- GROUP BY and HAVING
- JOINs
- CASE statements
- Subqueries
- CTEs
- Window functions
- Date analysis
- Product analytics
- Funnel analysis
- Cohort retention
